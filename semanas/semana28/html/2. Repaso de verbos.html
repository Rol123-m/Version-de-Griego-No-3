El sistema aspectual del griego

El Sistema Aspectual Griego

El griego no organiza sus verbos principalmente por tiempo cronológico (pasado, presente, futuro), sino por aspecto: la manera en que se concibe la acción.

🎯 Tres aspectos fundamentales:

  • Continuo: acción en desarrollo (presente, imperfecto)
  • Puntual: acción vista como un todo (aoristo)
  • Completado: acción terminada con resultados presentes (perfecto)

Fórmulas Clave

Primer Aoristo Activo:

Aumento + Raíz + σα + Terminaciones secundarias

ἐ + λυ + σα + α = ἔλυσα

Primer Aoristo Medio:

Aumento + Raíz + σα + Terminaciones medias secundarias

ἐ + λυ + σα + μην = ἐλυσάμην

Perfecto Activo:

Reduplicación + Raíz + κα + Terminaciones primarias activas

λε + λυ + κα + α = λέλυκα

Perfecto Medio/Pasivo:

Reduplicación + Raíz + Terminaciones primarias medio/pasivas

λε + λυ + μαι = λέλυμαι

Particularidades del Primer Aoristo

Verbos Contractos

La vocal contracta se alarga antes de -σα-:

  • ἀγαπάω → ἠγάπησα (α → η)
  • ποιέω → ἐποίησα (ε → η)
  • πληρόω → ἐπλήρωσα (ο → ω)

Raíces con Oclusivas

TipoLetras+ σEjemplo
Labialesπ, β, φ→ ψγράφω → ἔγραψα
Guturalesκ, γ, χ→ ξπνίγω → ἔπνιξα
Dentalesτ, δ, θ→ σπείθω → ἔπεισα

Aoristos Líquidos

El formativo -σα- se simplifica a -α-:

  • μένω → ἔμεινα
  • στέλλω → ἔστειλα
  • αἴρω → ἦρα
